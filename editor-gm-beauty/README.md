# Editor GM Beauty

Transforme vídeos brutos em conteúdo pronto para postar.

## Como executar a Fase 1 (interface)

Requisitos: Node 20+.

```bash
cd web
npm install
npm run dev        # abre em http://localhost:3000
```

Telas: `/` (dashboard), `/novo` (upload), `/editor/demo-1` (editor).
O backend (`api/`) é só um esqueleto; a interface ainda não depende dele.

Veja `ARCHITECTURE.md` para as decisões técnicas.
